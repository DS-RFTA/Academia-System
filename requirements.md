# Sistema de Gerenciamento de Academia

## Objetivo 

Desenvolver um sistema para gerenciar alunos, planos, professores e pagamentos. 
Substituindo o controle manual atualmente realizado em papel e planilha.

---

# Usuários do sistema

- Administrador
- Recepcionista
- Professor
- Aluno

---

## Problemas Identificados

- Demora para localizar informações dos alunos.
- Controle manual de pagamentos.
- Dificuldade para acompanhar matículas.
- Informações espalhadas em papel.
- Risco de perda de dados.
